## 收录标准

- 只收**创作者本人发布的原帖**、官方演示，或公开仓库中带署名的可复制提示词；搬运、纯转发不收。

- **必须有公开提示词**（≥80 字）与预览封面。
- 按 URL / 提示词哈希去重；README 每类展示代表作，完整列表见在线画廊。
- 互动数为整理时快照（2026-10-15 11:50 (UTC+8)）。导入条目在 `cases.json` 的 `source_attribution` 字段署名。

## Seedance 2.5 是什么

ByteDance Seed 团队在 Seedance 2.0 音视频联合架构上的下一代模型，强调：

- 单次生成约 **4–30 秒**音视频，并支持续写扩展
- 更强的多模态参照（多图 / 多视频 / 多音频）
- 面向「一口气讲完一段故事」的创作，而非只出 5 秒碎片

官方页面：[seed.bytedance.com/en/seedance2_5](https://seed.bytedance.com/en/seedance2_5) · 发布博文：[Introducing Seedance 2.5](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)

常见体验入口：即梦 / Dreamina、Jimeng、Doubao，以及 Higgsfield、Flova、OpenArt、CapCut AI Lab 等第三方。

## Agent Skills

本仓库同时提供可安装的 **Agent Skills**（Claude Code / Codex / Cursor）：

```bash
npx skills add xianyu110/awesome-seedance-2.5
```

### 如何安装 / 使用

1. 运行上面的 `npx skills add`，或把本仓库加为 skills 源。
2. 清单：`.claude-plugin/marketplace.json` · `skills/catalog.json`（当前 20 个技能）。
3. **分类技能包** `seedance-25-pack-*`：按 cinematic / lifestyle / character / fantasy / commercial / music / compare / other 打包，目录内 `prompts/` 为公开提示词精选，可直接复制到 Dreamina。
4. 导演总控：`seedance-25-prompt-director`；全库索引：`seedance-25-gallery-index`；主题示例（拳击 / 猫骑士 / 机甲等）仍保留。
