## 收录标准

- 只收**创作者本人发布的原帖**；搬运、纯转发别人视频的帖子不收。
- 作者在帖子里**明确写了是 Seedance 2.5**（含 Seedance2.5 / #Seedance2.5）。**不收录**仅写 Seedance / Seedance 2.0 / Mini / Fast 而未标明 2.5 的作品。
- 提示词只引用**公开可查**的内容：原帖正文或作者本人的回复；找不到出处的留空。
- 同一作者的相似作品只留代表作；按点赞数排序，互动数为整理时的快照（2026-10-13 20:58 (UTC+8)）。

## Seedance 2.5 是什么

ByteDance Seed 团队在 Seedance 2.0 音视频联合架构上的下一代模型，强调：

- 单次生成约 **4–30 秒**音视频，并支持续写扩展
- 更强的多模态参照（多图 / 多视频 / 多音频）
- 面向「一口气讲完一段故事」的创作，而非只出 5 秒碎片

官方页面：[seed.bytedance.com/en/seedance2_5](https://seed.bytedance.com/en/seedance2_5) · 发布博文：[Introducing Seedance 2.5](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)

常见体验入口：即梦 / Dreamina、Jimeng、Doubao，以及 Higgsfield、Flova、OpenArt、CapCut AI Lab 等第三方。API 常见模型 id：`dreamina-seedance-2-5-260628`。

## 玩法技巧

1. **先锁角色再动画**：用 GPT Image / Nano Banana 等出角色卡与场景静帧，再把图喂给 Seedance 2.5（见 @TomaAIbijo 的 GTA 风案例）。
2. **导演式提示词**：写清时长、画幅、光线阶段、镜头运动与 Negative（见 @johnAGI168）。
3. **生活流靠约束画质**：手持晃动、对焦犹豫、关掉美颜与 BGM，会更像真 DV（见 @fuji_ai_）。
4. **预演别硬喂**：复杂动作可先解析成文字，再只参照角色/背景，减少「带着硬动作」（见 @ni_naai）。
5. **先比再选型**：同提示词同参照做成本与画质对比（见 @ZetoGroovin）。
