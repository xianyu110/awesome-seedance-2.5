# Seedance 2.5 · Cinematic & Action

Turn ideas into **movie-trailer energy** shorts on Seedance 2.5. Patterns distilled from the curated gallery cases below (no private prompts invented as "originals").

> Gallery: [https://xianyu110.github.io/awesome-seedance-2.5/?cat=cinematic](https://xianyu110.github.io/awesome-seedance-2.5/?cat=cinematic) · Repo: [https://github.com/xianyu110/awesome-seedance-2.5](https://github.com/xianyu110/awesome-seedance-2.5)

## Workflow

1. Lock genre + stakes in one sentence (heist fail, underwater horror, streetball, war zone, mech bounty).
2. Pick duration 15–30s; aspect 16:9 for trailer, 9:16 for social cutdowns.
3. Write 4–6 timed beats (hook → escalate → peak → button).
4. Specify camera motivation and impact SFX; keep dialogue sparse unless needed.
5. If using character refs, apply `seedance-25-character-lock-i2v` rules.

## Recipe template

```text
MODEL: Seedance 2.5 | DURATION: 18s | ASPECT: 16:9
STYLE: photoreal cinematic, practical lighting, film grain light
AUDIO: no dialogue, impact SFX + short score swell, no subtitles

HOOK (0–3s): <striking visual cold open>
BUILD (3–10s): <obstacle / chase / contest>
PEAK (10–15s): <reversal or payoff>
BUTTON (15–18s): <lingering hero shot or hard cut to black>

CAMERA: motivated handheld/steadicam, no random whip pans
NEGATIVE: no watermark, no UI chrome, no beauty filter
```
